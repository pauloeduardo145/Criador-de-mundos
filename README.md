# 🌍 Criador de Mundos

Um aplicativo desktop desenvolvido em **Python** com **CustomTkinter**, criado para auxiliar escritores, roteiristas, mestres de RPG e criadores de universos fictícios na organização de suas histórias.

---

## 📸 Visão geral

O Criador de Mundos permite organizar todas as informações de um universo em um único lugar.

Com ele é possível criar histórias completas contendo personagens, capítulos, sistemas de poder, observações e referências visuais.

---

## ✨ Funcionalidades

* 📚 Gerenciamento de histórias
* 👤 Cadastro completo de personagens
* 🖼️ Imagem principal para personagens
* 🖼️ Galeria de imagens com descrição
* 📖 Organização por capítulos
* ⚡ Sistema de poder
* 📝 Observações
* ✏️ Edição de todos os elementos
* 🗑️ Exclusão de histórias, personagens, capítulos e observações
* 💾 Salvamento automático dos dados

## 🚀 Tecnologias utilizadas

* Python 3
* CustomTkinter
* Pillow (PIL)
* JSON
* UUID
* shutil
* tkinter

## ⚙️ Instalação

Clone o repositório:

```bash
git clone https://github.com/pauloeduardo145/Criador-de-mundos.git
```

Entre na pasta:

```bash
cd Criador-de-mundos
```

Instale as dependências:

```bash
pip install -r requirements.txt
```

Execute:

```bash
python interface.py
```
